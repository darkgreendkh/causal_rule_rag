# 毕业论文初稿结构与资料核验记录

本文件是写作依据与目录，不是论文正文或实验报告。依据 `docs/参考/实验计划.docx`、前辈送审修改版论文的 OOXML 样式与目录、`data/research_papers/` 八份 PDF，以及已批准的七章方案整理。核验日期：2026-09-14。后续正文须以最终代码、真实运行记录和实际实验为准；当前不填造实验数值或结论。

## 一、参考论文可借鉴的结构与排版

前辈论文的结构是“绪论—基础理论—两个关键方法章—方法整合章—实验章—总结展望”。目录依次包含摘要、Abstract、图清单、表清单，七章正文，致谢和参考文献。封面、授权页及致谢中的姓名、学号、导师、学院等个人信息均不移植。

| 部分 | 前辈论文的实际结构 | 本文可采用的组织方式 |
| --- | --- | --- |
| 第 1 章 | 背景意义、三类研究现状、研究内容、技术路线与创新点、内容安排 | 对应政策问答、图谱检索、规则与流程纠错三类研究现状 |
| 第 2 章 | 问题定义、相关特性分析、各类基础理论、章末小结 | 明确规范规则、文本关系、经验因果三者的边界，定义任务及符号 |

## 二、七章目录与字数分配

暂定题名：**基于规则约束与因果增强的智能审批关键技术研究**。副标题或摘要中应明确应用场景为社保与住房公积金政策辅助办理，系统提供模拟和解释，不代替行政审批决定。正文目标约 3.5 万字，参考文献、目录与图表占位不用于机械凑字数。

### 第 1 章 绪论（约 4,500 字）

- 1.1 研究背景与意义：政策分散、地域与时间适用性、跨条款办理条件、可解释办理支持。
- 1.2 国内外研究现状：1.2.1 检索增强生成与知识图谱；1.2.2 图社区与多跳路径检索；1.2.3 规则推理、规划与流程纠错。
- 1.3 研究问题与研究内容：知识构建、检索组织、可执行推理三条主线。
- 1.4 技术路线与拟验证创新点：区分系统能力、方法设计和待验证效果。
- 1.5 论文组织结构。

### 第 2 章 相关理论与问题定义（约 4,500 字）

- 2.1 政策辅助审批任务与适用范围：36 份政策材料及六类事项，八篇文献仅作背景参考。
- 2.2 文本分块、向量表示、RAG 与图检索基础。
- 2.3 规则表达式、三值逻辑与事实角色：申请人事实、政策参数、外部确认。
- 2.4 宏观关系、微观规则、证据追溯及双层图谱定义。
- 2.5 图社区、方向路径与结构评分。
- 2.6 状态转移、序列编辑与受约束修复问题。
- 2.7 本章小结。

必须说明：文本提到的原因或条件不等于已识别的经验因果；本文“因果增强”主要指有证据的方向关系、规则前置依赖与状态转移，不估计现实中的因果效应。缺失事实为 unknown，不转换成 false；规则不适用、规则被违反、资料缺失分别报告。

### 第 3 章 规则约束的双层知识图谱构建（约 6,500 字）

- 3.1 引言与跨文档、跨条款知识组织难点。
- 3.2 多源政策解析、稳定标识、条款单元与适用域。
- 3.3 宏观关系构建及结构化抽取证据。
- 3.4 微观可执行规则、动作和事项建模。
- 3.5 RPC 一致性约束：输入、定义、计算、适用边界以最终实现为准。
- 3.6 SCS 跨层支持评分与融合图构建：不得直接沿用计划中未落地的公式。
- 3.7 候选规则审核、批量启用、停用与知识更新。
- 3.8 全量材料覆盖清单、事项能力和缺口标识。
- 3.9 本章小结。

原始材料涵盖养老、医疗、失业、工伤、生育、住房公积金六类及共用参保经办内容。所有条款单元需有“映射到事项/有原因排除”记录；全部可办理事项均进入目录。不得用两个可运行示例替代全量覆盖。对缺少办理步骤、引用外部办法、有效期不明、参数缺失、需要经办机关决定等情况，明确说明为何仅可检索、检查或局部模拟。

### 第 4 章 约束社区与多跳路径检索（约 6,000 字）

- 4.1 引言与语义相近但条件不适用的问题。
- 4.2 事项、地域和时间约束下的社区组织。
- 4.3 层次社区划分与不可拆分情况处理。
- 4.4 查询解析、候选节点定位与方向路径搜索。
- 4.5 语义、规则支持和路径结构联合排序。
- 4.6 证据去重、冲突与信息不足处理。
- 4.7 基础对照和消融配置入口。
- 4.8 本章小结。

最终算法若是自定义约束划分或启发式搜索，不得直接写成 Louvain/Leiden 或精确全局优化。社区边界、路径方向和评分中各项权重都应可由代码/运行记录复现；没有运行的对照算法只列入第 6 章实验计划。

### 第 5 章 可解释问答、流程纠错与系统实现（约 5,500 字）

- 5.1 总体架构及知识、推理、交互三层衔接。
- 5.2 向量、普通图增强和规则因果增强问答模式。
- 5.3 基于三值逻辑的条件检查与首错定位。
- 5.4 规则内反事实模拟和最小序列修复。
- 5.5 下一步动作推荐、状态预览和显式应用。
- 5.6 前后端、API、存储与构建任务设计。
- 5.7 概览、文档与规则审核、图谱、问答与流程工作台四页实现。
- 5.8 本章小结。

修复只能改变拟执行步骤，不修改不可撤销的办理历史、不可变事实、政策参数或外部审批结果。“最小”限于明示编辑代价、允许动作、搜索状态边界和搜索是否穷尽；截断时必须报告，不能声称全局最优。界面预览后应用的状态是本次本地模拟，不代表真实事项已经办结。

### 第 6 章 实验设计与结果分析（约 6,500 字，结果留空）

- 6.1 数据集、条款/事项划分、标注协议和质量控制。
- 6.2 环境、模型、提示词版本、配置、参数与运行预算。
- 6.3 评价指标及统计方法。
- 6.4 双层图谱构建对比与消融实验。
- 6.5 社区划分、多跳检索对比与消融实验。
- 6.6 问答、条件检查、流程修复与下一步推荐实验。
- 6.7 知识更新、缺口与系统运行案例分析。
- 6.8 结果讨论、失败案例和有效性威胁。
- 6.9 本章小结。

本章现在写清研究假设、输入输出、对照、指标、数据划分和结果模板；所有结果填“待实验”，所有图用明确占位，不绘制假数据曲线，不写“显著提升”“验证有效”等结果性结论。工程单元测试和接口联调可写为实现验证，不能混作正式论文实验。

### 第 7 章 总结与展望（约 1,500 字）

- 7.1 工作总结：按三条主线逐项总结实际完成的机制及系统能力，单独列出效果待验证项。
- 7.2 局限与展望：有限政策覆盖、专家审核、参数更新、真实业务联通、更严格因果建模等。

前置部分另设中英文摘要、关键词、目录、图清单、表清单；实验完成前摘要只写方法与系统实现，不写未经获得的实验结论。附录可放字段表、规则语法、事项覆盖清单、提示模板与实验配置。
