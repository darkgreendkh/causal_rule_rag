## 已实现的代表流程及验证

- 养老：参保申请→登记完成；关系转移申请、接收、原地转出及新地办结。
- 医疗：异地备案申请→备案确认→直接结算；手工报销准备→提交→结果登记。
- 失业：单位终止关系证明→失业登记→登记确认；失业金、培训或自谋职业待遇申请与核定。
- 工伤：材料准备→申请→受理→认定/不予认定→送达；另有补正、劳动能力鉴定、再次鉴定和手工报销。
- 生育：病历准备→津贴提交→核定结果；护理津贴和医疗结算。
- 公积金：灵活就业协议→开户申请→开户确认；缴存、提取和各类贷款审批、签约、抵押与发放步骤。

`test_policy_catalog.py` 含 55 条条件规则的手写正常/违规/缺信息例，以及 OR/例外分支；六类代表流程分别验证三值结果和补回遗漏前置动作的最小修复。外部机构动作只有原始事实已确认时才允许登记，不能因“下一步”或“修复”产生真实批准。

## 资料不足与必须保留的未知

初始输出中 468 个单元缺少可确认的明确施行日期，包含发布说明；15 条已核对规则因此不能在流程中直接得到已知适用结果。`active` 表示语义核对与启用状态，不替代作用域校验。

| 缺口 | 当前处理 |
| --- | --- |
| 仅写“自公布之日起”但缺少可确认具体日期，或仅有抓取时间/页面月份 | 不把抓取日期、页面月份当施行日；scope unknown |
| 2020 年失业补助、旧医疗救助及试行公积金等历史资料 | 保留原版本与期限；不能用于声称当前仍可申请 |
| 只规定施行日，未规定终止日 | 保留开放结束；明确未核验后续修订和清理状态 |
| 社平工资、年度补贴、医保目录、当地限额、流动性与其他配套规定 | 未提供对应参数不推算当前值；资料缺口不判作申请人违规 |
| 贷款信用标准、房产记录、退休边界、比例与最终额度 | 分项事实与外部核查；本包不提供完整最终贷款金额计算 |
| 公积金旧细则与较新指南的倍数、系数、还贷比例或退休口径不同 | 保留各自来源，不拼成无版本的统一现行规则 |
| 劳动能力、工伤性质、医疗救助身份、银行审批、资金实际支付 | 必须提供已确认的外部结果；当前未联网认证这些事实 |
| 未完整结构化的办理分支 | 保留覆盖与具体来源缺口；“申请已提交”目标不代表全部资格或额度获批 |

PDF 只作为背景资料，当前没有进入双层政策规则图。宏观—微观的关联依据明确引文及动作身份，不是任意跨文件实体自动融合；没有资料支撑时不能生成跨来源审批结论。

## 审核来源与版本

- `implementation_source_review`：实现阶段针对清单中具体源字节版本核对的初始规则，不是法律专家或主管机关审核。
- `unreviewed_model_candidate`：模型输出，尚未启用；无法完整表达或引文错误会保留校验问题。
- `source_changed_requires_review`：已核对源版本变化，旧固定阈值或动作不能自动沿用；必须重新审查语义，不能仅更新哈希或直接点击启用。
- `local_ui_source_review`：本地界面执行审核操作的记录，不代表专业资质。审核记录应绑定规则条件、scope 和 evidence 指纹。

来源变化首先使旧快照失效；新构建仍须通过初始清单核对。缓存命中、引用仍存在、旧 rule_id 相同或编译测试通过，都不等于新政策已完成语义审核。

## 生成命令、缓存与构建版本

在项目根目录执行以下 PowerShell 命令，只解析本地资料并生成来源 JSON，不调用付费模型，不进行正式科研实验：

```powershell
Set-Location D:/bylw/causal_rule_rag/backend
$env:PYTHONUTF8 = '1'
.venv/Scripts/python.exe -c "from pathlib import Path; import json; from app.corpus import build_corpus,PARSER_VERSION; c=build_corpus(Path('../data')); p=Path('../.runtime/research/source-corpus.json'); p.parent.mkdir(parents=True,exist_ok=True); p.write_text(json.dumps(dict(c,parser_version=PARSER_VERSION),ensure_ascii=False),encoding='utf-8'); print({k:len(v) for k,v in c.items()})"
```

| 文件/标识 | 用途与失效依据 |
| --- | --- |
| `.runtime/research/source-corpus.json` | 可再生解析导出，包含完整来源和当时目录；不是正式数据库版本头 |
| `.runtime/research/source-cache/` | PDF 页文本缓存，校验来源相对路径、文件 SHA-256 与 parser_version |
| `PARSER_VERSION=policy-units-v3-pdf-text-v1` | 当前文本解析标识；不代表规则包版本或政策有效性 |
| 每单元 `source_sha256` | 固定规则清单核对依据；旧导出缺少此值时不能沿用初始 active 状态 |
| `.runtime/research/embeddings.json` | 按模型名+文本摘要复用向量，跨配置复用文本计算 |
| `.runtime/research/snapshots/<build_id>.json` | 完整研究配置、语料、图、向量、语料指纹和来源文件摘要 |
| `ResearchHead` | 各 namespace/profile 当前已完成快照；build_id 每次实际构建生成 |
| `rule_reviews.json` / `candidate_rules.json` / `excluded_sources.json` | 审核、候选与从研究库排除的来源记录 |
| `.runtime/research/runs.jsonl` | 构建、问答和流程工程运行记录，包含 build_id 和配置 |

导出更新不等于已完成 Neo4j 构建。最终可用 build_id、HTTP 与前端验收结果由主集成任务记录；本文不填写未实际验证的构建成功、问答质量或实验指标。
