## 与实现逐项对照

- 构建：对照 `backend/app/corpus.py`、`policy_catalog.py`、`causal_graph.py`。微观规则包的实现阶段原文核对不称为独立专家审核；覆盖清单不称为全部条款已结构化。
- RPC：三个分量等权，continuity 是布尔 DSL/字段/动作引用闭合，不是事实正确率。temporal 检查结构范围和正向循环，业务请求日期由 workflow 判断。
- 版本：同规范标题、同地域才比较文号，缺身份或版本输出 unknown；不同规范的文号不同不构成冲突。本文没有宣称由文号证明规范现行有效。
- SCS：真实 BGE 稠密向量相似度，缺省为零；类型分量在当前条款到规则候选类型中为一；身份对应关系另行解释。未宣称实现 BGE 稀疏及多向量分支。
- 社区：强约束并查集收缩、组间范围交叉检查、自环权重保留。顶层 Leiden modularity；子层 Leiden CPM，分辨率 `0.5 * level`，默认上限三层。没有冒充宏观文本、微观文本分别训练的两级社区模型。
- 查询：第一层社区均值粗筛；默认三个社区、九个种子；有向栈式候选生成，默认六跳、一百候选；不是 Dijkstra，也不保证全图最优。
- 评分：路径语义/RPC/集中性权重 0.4/0.4/0.2；熵概率是相似度 softmax 构造权重，不是现实业务转移概率。
- 校验：规则与动作都检查，按路径顺序重放实际动作的允许效果；缺少前缀完成信息为 unknown，已知 False 仍 violated；首个阻断后停止推进并标明未验证后缀，外部结果仍需原始事实确认，已知历史不重复改写。检索路径不替代用户明确序列的 workflow 核查。
- 证据：完整规则引用及动作检查引用进入预算；默认八来源、五路径；缺失来源、引用不符、超预算的诊断记录标记未用于回答，不进入生成提示。只对现有规则包补齐，不宣称库外配套证据完备。
- 消融：without_semantic 仅取消路径语义评分，不取消社区/种子相似度；without_evidence_chain 只移除 paths，保留规则检查和缺口。没有把普通图基础对照称为外部 GraphRAG 的完整复现。
